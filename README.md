# LiveHelper

用于在OBS显示游玩歌曲以及游戏内统计数据的Mod。

## 版本依赖

- BSIPA: ^4.3.5
- BeatSaber: 1.45.1+

## 安装方式

1. 已安装BSPIA框架
2. 从[Release](https://github.com/Hellobaka/BeatSaber_LiveHelper/release/latest)下载文件，并在游戏根目录解压

## OBS添加源方式

OBS 中新增“浏览器”源，地址填 `http://127.0.0.1:6735/overlay`，建议宽高设为 1920×1080。暂停与结算画面保留并冻结统计，进入歌曲选择界面时隐藏。
